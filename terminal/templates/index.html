ATIVAÇÃO DESTE COMPUTADOR

Conecte o caixa à empresa

Esta configuração é feita uma vez. No painel da empresa, abra Assinatura para copiar a chave da licença e Terminais para criar este caixa e gerar o código de pareamento.

A licença identifica a assinatura; o código de pareamento autoriza este dispositivo por uma única vez. Depois, cada operador entra com seu próprio PIN.

No Docker local, use http://cloud:8080. Em outro computador, use o endereço HTTPS informado no painel. ID deste dispositivo:

Isso preserva o banco atual em um backup e cria um diretório de dados separado para o próximo pareamento.

ACESSO DO OPERADOR

Pronto para vender

Selecione seu nome e digite sua chave de operador (PIN) cadastrada em Equipe no painel da empresa. Ela é diferente da senha web.

Nenhum operador com PIN está disponível para este terminal. Cadastre um PIN no painel da empresa e clique em “Atualizar operadores”.

Com vendas, caixa ou movimentações neste computador, preserve este banco e use uma instalação ou diretório de dados novo para outra empresa.
