Dúvidas frequentes

Tudo claro, desde o começo.

Estamos abrindo a base para testes enquanto construímos os módulos de operação comercial.

Já posso vender com o sistema?

Ainda não. Esta versão permite criar empresa, lojas, usuários, produtos e movimentações de estoque. O caixa local existe como protótipo técnico, mas interface operacional e NFC-e precisam ser concluídas e testadas antes do piloto em loja.

Quando serei cobrado?

Não há cobrança ativa. Os preços são planejados para o lançamento. O cadastro atual cria assinatura de teste no Essencial.

Preciso de um servidor na loja?

O plano é que uma loja com um caixa não precise. Um servidor local será opcional para operações com vários terminais.

E se a internet cair?

O futuro aplicativo de caixa local está sendo projetado para continuar registrando operações e sincronizar depois, dentro das regras fiscais aplicáveis. Essa função ainda não está disponível.
